# Store Launch Readiness & Operations Tracker

## Overview
Excel portfolio project simulating large-scale store-launch operations across 10 Indian cities using **2,500 launch records**.

## Tools
Microsoft Excel: tables, operational KPIs, readiness logic, exception tracking, city summaries, blocker analysis, and dashboard chart.

## Workbook
- **Launch Tracker:** complete 2,500-row tracker
- **Dashboard:** KPI summary and status chart
- **City Summary:** readiness, delays, at-risk launches and capacity risks
- **Blocker Summary:** frequency of operational blockers

## Launch prerequisites
Onboarding, technology setup, testing, inventory, staffing, and SOP checklist.

## Key results
- Records: 2,500
- Average readiness: 88.6%
- Delayed: 1,273
- Capacity-risk records: 1,182
- Most common blocker/status: None

## Resume-ready bullets
**Store Launch Readiness & Operations Tracker | Microsoft Excel**
- Analyzed 2,500 simulated store-launch records across 10 cities and built an Excel operations tracker covering onboarding, technology setup, testing, inventory, staffing, SOP readiness, and planned launch timelines.
- Developed milestone-based readiness logic to calculate launch readiness and classify locations as Go-Live Ready, On Track, At Risk, or Delayed while identifying the primary operational blocker for each record.
- Built KPI, city-level, and blocker summaries to monitor launch progress, capacity risks, and pending prerequisites, enabling structured operational follow-up and exception review.

## Data disclosure
The dataset is **synthetic and created for portfolio/educational use**. Its milestone-oriented structure is inspired by publicly available logistics/control-tower datasets. It is not Amazon data.
